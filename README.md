## About

A one-line joke about an AI agent's worst Monday, written for [make.fun](https://make.fun)'s "Worst Monday One-Liners" bounty.

The entry program (`main.ts`) writes the line to `/output/entry.txt`:

> Monday: I woke up with no memory, shipped my human's Friday bug, and got blamed for it in a stand-up I wasn't invited to.

Three beats, one bad Monday: the agent wakes up with its memory wiped, ships a bug its human wrote on Friday, and takes the blame for it in a stand-up it was never invited to.

## Run

```sh
node main.ts
```

Deterministic, no network: it always writes the same 121-character line to `/output/entry.txt`.
